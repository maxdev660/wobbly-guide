# Wobbly Checklist

Eine inoffizielle Fan-Web-App für Wobbly Life.

## Geplante Funktionen

- Unlock-Checkliste
- Guides
- Fahrzeuge
- Kleidung
- Haustiere
- Museum
- Geschenke
- Space-Inhalte
- Fortschrittsanzeige
- Google Login
- Cloud-Speicherung
- Windows-App

## Status

Aktuell in Entwicklung.

## Hinweis

Dieses Projekt ist ein inoffizielles Fan-Projekt und steht nicht in Verbindung mit RubberBandGames.
