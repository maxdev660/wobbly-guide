# 🇩🇪 Deutsch

## Über Wobbly Guide

Wobbly Guide ist ein inoffizielles Fan-Projekt für **Wobbly Life**.

Das Ziel des Projekts ist es, eine übersichtliche Plattform zu erstellen, auf der Spieler Informationen zu Freischaltungen, Aufgaben, Sammelobjekten und Geheimnissen finden können.

Die Website soll außerdem ermöglichen, den eigenen Fortschritt zu speichern und erledigte Aufgaben abzuhaken.

## 🌍 Sprachen

Wobbly Guide unterstützt:

- 🇩🇪 Deutsch
- 🇬🇧 Englisch

Beim ersten Besuch erkennt die Website automatisch die Sprache des Browsers bzw. Betriebssystems.

Die Sprache kann anschließend jederzeit manuell geändert werden.

Die gewählte Sprache wird lokal gespeichert.
