# 🇬🇧 English

## About

**Wobbly Guide** is an unofficial fan project for **Wobbly Life**.

The goal of Wobbly Guide is to provide one clear place where players can find unlocks, tasks, collectibles, secrets and step-by-step guides.

Players will also be able to track their progress and mark completed unlocks.

## Features

- ✅ Unlock checklist
- 📖 Step-by-step guides
- 🚗 Vehicles
- 👕 Clothing
- 🐶 Pets
- 🎁 Gifts
- 🏛️ Museum collections
- 🚀 Space content
- 🔐 Secrets
- 🧩 Tasks and challenges
- 🔎 Search and filters
- 📊 Progress tracking
- 💾 Local progress saving
- 👤 Google sign-in
- ☁️ Cloud synchronization
- 🇬🇧 English
- 🇩🇪 German
- 💻 Windows app

## Languages

Wobbly Guide supports:

- 🇬🇧 English
- 🇩🇪 German

On the first visit, the website automatically detects the browser or system language.

Users can manually switch between English and German.

The selected language is saved in the browser.

## Progress Tracking

Players will be able to mark unlocks as completed.

Example:
☑ Vehicle unlocked
☑ Pet found
☑ Gift collected
☐ Complete museum collection
☐ Unlock secret outfit

Completed items will count towards the total progress.
Accounts
Google sign-in is planned.
With an account, users will be able to synchronize their progress between devices.
The website will still work without an account.
Guest progress will be stored locally in the browser.
Windows App
A Windows version of Wobbly Guide is planned.
The website and Windows app are intended to use the same:
- guides
- unlock data
- account
- progress
- language settings
The Windows app is also planned to support offline usage.
Technology
Currently used:
- HTML
- CSS
- JavaScript
- JSON
- GitHub
- Cloudflare Pages
Planned for later:
- Firebase Authentication
- Firestore
- Tauri
Status
Wobbly Guide is currently under development.
More unlocks, guides and features will be added over time.

# 🇩🇪 Deutsch


# Über das Projekt
Wobbly Guide ist ein inoffizielles Fan-Projekt für Wobbly Life.
Das Ziel von Wobbly Guide ist es, eine übersichtliche zentrale Seite zu erstellen, auf der Spieler Freischaltungen, Aufgaben, Sammelobjekte, Geheimnisse und Schritt-für-Schritt-Guides finden können.
Spieler sollen außerdem ihren Fortschritt verfolgen und erledigte Freischaltungen abhaken können.
Funktionen
- ✅ Freischaltungs-Checkliste
- 📖 Schritt-für-Schritt-Guides
- 🚗 Fahrzeuge
- 👕 Kleidung
- 🐶 Haustiere
- 🎁 Geschenke
- 🏛️ Museum-Sammlungen
- 🚀 Weltraum-Inhalte
- 🔐 Geheimnisse
- 🧩 Aufgaben und Herausforderungen
- 🔎 Suche und Filter
- 📊 Fortschrittsanzeige
- 💾 Lokale Speicherung
- 👤 Google-Anmeldung
- ☁️ Cloud-Synchronisierung
- 🇩🇪 Deutsch
- 🇬🇧 Englisch
- 💻 Windows-App
# Sprachen
Wobbly Guide unterstützt:
- 🇩🇪 Deutsch
- 🇬🇧 Englisch
Beim ersten Besuch erkennt die Website automatisch die Browser- beziehungsweise Systemsprache.
Die Sprache kann jederzeit manuell zwischen Deutsch und Englisch gewechselt werden.
Die ausgewählte Sprache wird im Browser gespeichert.
Fortschritt
Spieler sollen Freischaltungen als erledigt markieren können.
Beispiel:
☑ Fahrzeug freigeschaltet
☑ Haustier gefunden
☑ Geschenk eingesammelt
☐ Museum-Sammlung abschließen
☐ Geheimes Outfit freischalten

Erledigte Einträge zählen zum gesamten Fortschritt.


# Accounts
Eine Anmeldung mit Google ist geplant.
Mit einem Account soll der Fortschritt zwischen verschiedenen Geräten synchronisiert werden können.
Die Website soll trotzdem auch ohne Account funktionieren.
Der Fortschritt von Gästen wird lokal im Browser gespeichert.


# Windows-App
Zusätzlich zur Website ist eine Windows-Version von Wobbly Guide geplant.
Website und Windows-App sollen dieselben:
- Guides
- Freischaltungsdaten
- Accounts
- Fortschrittsdaten
- Spracheinstellungen
verwenden.
Für die Windows-App ist außerdem Offline-Unterstützung geplant.
